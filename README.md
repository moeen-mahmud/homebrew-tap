# homebrew-tap

Homebrew formulae for Moeen Mahmud's tools.

```bash
brew tap moeen-mahmud/tap
brew install dispach
```

| Formula | What it is |
| --- | --- |
| `dispach` | A lightweight, model-agnostic AI agent runtime — [moeen-mahmud/dispach](https://github.com/moeen-mahmud/dispach) |

## Updating a formula

Each formula is generated by its own project and copied here — the digests must be of the bytes a
release actually published, so nothing in this repository computes them. For `dispach`:

```bash
gh release download v<version> --repo moeen-mahmud/dispach --pattern dispach.rb --clobber --dir Formula
brew audit --strict --formula ./Formula/dispach.rb
```

Commit the diff after reading it. The four `sha256` lines are the whole review.
